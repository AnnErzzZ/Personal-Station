# AIGC 面试问答参考

使用方法：每题记住回答顺序，用自己的话讲。通常控制在 30–60 秒，作品介绍可以讲两分钟。下文是表达参考；留空处按真实情况补充。当前视频尚未完成，完成后再更新进度表述。

## 1. 简单介绍一下自己

记住：上一份岗位 → 主要工作 → AI 实践 → 求职方向。

参考：我叫伍子荣，上一份工作是交互设计师，主要负责智能空间 Web 平台、小程序和 B 端产品的 UX/UI，也跟进研发走查和验收。工作中接触过 ChatGPT、即梦和 Codex，也参与过 AI Agent 的体验设计。这次希望应聘 AIGC 设计相关岗位，把已有的需求理解、视觉设计和修改交付经验用到图像与视频制作中，并进一步熟悉贵司的制作流程和交付要求。

当前人物、场景与视频练习是为本次面试准备的，用户希望通过实做展示快速学习能力。自我介绍不主动展开这套练习；对方询问作品时再简要展示，并说明学习、测试、修改和实际进度。

## 2. 为什么离职

记住：真实原因 → 已有经验 → 下一份工作的方向。

参考：我上一份工作主要负责交互和 UI 设计，也积累了需求理解、研发协作和交付经验。离职主要是____。目前在寻找下一份工作，也在继续做 AIGC 作品，希望进一步了解贵司的制作流程和岗位要求。

这题的原因尚未确认，必须用自己的真实情况补充。职业方向可以解释求职选择，不能直接替代实际离职原因。

## 3. 离职后这段时间在做什么

记住：实际安排 → 具体产出 → 当前进度。

参考：目前我在整理作品集、准备求职，也在继续尝试 AI 工具。最近为这次面试准备了一次针对性的 AIGC 制作练习，想通过实做熟悉流程。如果需要，我可以展示实际产出和制作过程。

如果被问到整个离职期间的安排，按真实时间线补充，不将当前制作说成从离职开始一直在做。

## 4. 为什么从 UX/UI 转向 AIGC

记住：实际接触 → 做过的尝试 → 希望继续做什么。

参考：我在设计工作中已经开始接触 AI 图像生成，也尝试将 AI 用于动效和页面实现，希望继续深入这类工具在内容制作中的应用。过去的设计经验可以帮助我理解需求、判断视觉效果、按反馈修改，并推进交付。

## 5. 你的优势和需要补足的地方

记住：两项优势及证据 → 一项具体短板 → 当前补足行动。

参考：我的优势是需求理解和设计落地。以前的工作需要把业务需求整理成流程和界面，再跟进研发、走查和验收。AIGC 方面，我目前有图像生成和迭代实践，视频作品还在制作中，完整视频的制作和交付经验需要继续积累。我正在用现有的人物、场景素材做短片段验证。

## 6. 你会哪些工具，熟练到什么程度

记住：工具 → 实际用途 → 能独立完成的范围。

参考：我使用过 ChatGPT 图像生成、即梦和 Codex。当前 AIGC 作品主要是人物和场景多视角素材，具体使用的工具、Prompt 和修改过程可以结合文件展示。Codex 主要用于辅助 SVG、动效和页面实现。视频部分目前还在推进，我会按实际完成情况说明自己的能力范围。

简历列有 PS、AE，需补一句真实例子：我用____做过____，目前能独立完成____。如果被问到 ComfyUI、模型训练等未确认的能力，按实际接触情况回答。

## 7. 介绍一下你的 AIGC 作品

记住：作品设想 → 已有素材 → 一次具体修改 → 当前阶段。

参考：我为这次面试准备了一次针对性的制作练习，想通过实做熟悉这类内容的流程。可以给您看一下现有素材，并介绍我是怎么学习、测试和修改的。这套练习计划做____，制作过程中遇到的问题是____，后来通过____调整，结果是____。

具体进度按现场实际产出说明：已有的人物与场景多视角素材，以及完成后可展示的约十秒片段。视频未完成时不描述为已有成片。快速学习用学习步骤、实际投入时间、修改证据和结果来说明，时间未经确认不填写。

填入真实题材和修改案例。如果暂时只有生成结果，就说明实际生成过程；完成动态片段后，再说明验证结果。

## 8. 给你一个短视频需求，会怎么做

记住：明确需求 → 分镜和关键画面 → 动态生成 → 检查与修改 → 后期交付。

参考：我会先确认用途、时长、画幅、风格和交付时间，再拆分镜，确定每个镜头的主体、动作和运镜。然后准备人物与场景参考、关键画面，逐镜头生成和检查。遇到人物变化、物体变形或动作不对，会定位问题，调整输入或简化动作，再验证结果。后期和输出环节按具体任务及团队分工安排。

这是拟议制作方法，尚未完成的环节按计划介绍。长视频产能、剪辑与声音能力需要用实际作品说明。

## 9. 怎么保证人物和场景一致

记住：统一参考 → 明确约束 → 逐图逐镜头检查 → 针对问题修改。

参考：我会先准备统一的人物和场景参考，明确脸、发型、服装、配饰和画风这些关键特征。生成后检查不同视角和镜头里的变化，再针对具体问题调整。场景还需要检查布局、物体位置和光线。我目前有多视角素材，视频里的连续性还需要用实际片段验证。

已经亲自完成的检查可以讲具体例子；还没验证的做法按后续方法说明。参考素材不能作为一致性已经得到保证的证据。

## 10. Agent 和 RAG 项目里，你负责什么

记住：具体职责 → 一个设计例子 → 个人与团队分工。

参考：我主要负责 Agent 的整体 UX/UI、查询和追问体验，以及回答结构设计。例如围绕问题组织结论、指标、图表、明细和口径说明，帮助用户核对回答。我也参与过 RAG 知识库搭建，具体参与内容可以进一步说明。

准备补充：知识库里你实际整理或处理了什么、与谁协作。简历里的“8 个后端 Tool”也要准备说明它们与查询、回答结构的关系，技术实现按真实分工回答。

## 11. 期望薪资多少

记住：此前薪资 → 当前期望 → 薪资构成。

参考：我上一份薪资是 7.5K，目前期望固定月薪 8–9K，可以结合岗位职责和考核要求沟通。也想了解试用期薪资，以及项目提成如何计算和结算。

入职时间按实际情况回答，尚未确认能到岗的日期不作承诺。

## 12. 能接受三天培训和考核吗

记住：已有沟通立场 → 确认安排 → 决定是否参加。

参考：之前了解到前三天主要是理论和岗前培训，我愿意进一步了解。想先确认每天的时长、培训与考核内容、通过标准，以及通过后对应的岗位和入职安排，再确定参加。
