## 本轮交付检查

- [ ] 原稿保留，展示副本与业务事实分开。
- [ ] 每页有清楚的设计判断，图与文对应。
- [ ] 设计目标能追溯到前面的需求与痛点，目标与已验证成效分开。
- [ ] 标题简短直白，正文没有整段加粗，共同需求有明确归组。
- [ ] 用户指定的逐项说明已保留，每项对应实际界面或入口。
- [ ] 每页视觉设计前均已查看具体参考，来源、片段和借鉴点有记录，成稿已对照检查。
- [ ] 特写没有裁掉入口、对象或必要操作，尺度合理。
- [ ] 样机与说明按可见边缘对齐，屏幕贴合正确。
- [ ] 字体、卡片材质、图标与背景统一；色块值准确。
- [ ] 没有缺图、文字溢出、容器内部重叠、重复状态栏和不合理遮挡。
- [ ] 本机字体可用性已核对；轮廓字和可直接编辑文本的范围已说明。
- [ ] 指标、贡献和未来计划与确认来源一致。
- [ ] 相关修改已截图检查，当前节点与采用参考已记录。
