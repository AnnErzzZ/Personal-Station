### 毛玻璃从现有节点提取

材质源节点 `478:17511`，先核对再复制 fills、strokes、effects，保留目标卡片自己的尺寸和圆角。

- 径向渐变：冷灰 `#5F6367` 约 30% → 深灰 `#0C0D10` 约 12%。
- 背景模糊：18px。
- 1px 内描边：白色渐变高光，透明度约 20% → 65% → 20%。
- 卡片大多圆角 24；部分紧凑设备卡为 20。

这里只是便于识别材质，渐变方向与变换矩阵以节点实际属性为准，不用四个色值近似整套表现。该材质也用于总结、验证页卡片，以及规范页两块原白底板；规范色块保留真实颜色。

## 真实踩坑转成的方法

| 出现的问题 | 本次修正 | 后续复用的判断 |
| --- | --- | --- |
| 前两屏有效信息只在上半屏，整机过长 | 改带机框裁切卡片 | 按有效信息选完整与局部 |
| 小提示条、队列、弹窗放得巨大 | 恢复手机上下文和接近的 UI 尺度 | 冲击力优先来自主次和留白 |
| 设计点没有与样机左对齐 | 改按可见机身边缘 | 检查 PNG 透明边距 |
| 策略入口在底部却展示顶部 | 使用底部机框特写 | 裁切必须跟随证据位置 |
| 策略库一张内容图缺失 | 回到原素材补齐 | 不用渐变假图掩盖缺图 |
| 绑定页只说退出保存，内容太轻 | 展示真实发现、核对、保存链 | 补机制或合并，不补空话 |
| 规范页加入没有实质内容的系统描述 | 收敛为真实字体与色彩 | 规范按已有交付范围展示 |
| 大面积白底刺眼 | 深色毛玻璃底板＋亮字 | 展示容器与规范色值分开 |
| 笔记本台面像悬浮薄板 | 一体受光的机身与台面场景 | 检查空间、接触和材质 |
| 手册页文字堆积 | 标题＋用途句＋三个短要点 | 让真实交付材料占主位 |
| 验证页忘记已有对比数据 | 查事实文档恢复口径 | 先读已有事实，再说没有数据 |
| 总结编入未确认的后续计划 | 改为真实项目状态 | 不为填卡片编造规划 |

以上结果来自本次制作与用户反馈，不构成新项目必须使用同样视觉的要求。
